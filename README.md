# CG-Projeto_Final

Neste projeto, tenho como objetivo o desenvolvimento de um jogo como Super Mario. 

Por ja haver tantos diferentes platformers, eu decidi implementar uma mecanica que me permitisse destacar ester projeto de outros ja existentes.


O "bread-n-butter" deste projeto e a perspective shift. 


Esta mecanica permite ao utilizador, atraves da tecla TAB, mudar a perspetiva do jogo de 2D para 3D, permitindo-lhe resolver problemas que nao sao ultrapassaveis em apenas uma das duas dimensoes (por exemplo, no nivel 2)


o jogo ainda nao esta acabado. Tive varias dificuldades na resolucao do projeto o que atrasou o seu desenvolvimento, desta forma, ainda nao ha UI, apenas temos um ficheiro que funciona como level manager, permitindo despawning quando chegamos ao fim de um nivel e spawning no inicio do nivel seguinte 


CONTROLOS:

W A S D  +  SPACE  +  TAB
